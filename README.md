# RepairCalc

RepairCalc — микросервис для расчёта ремонта и подбора строительных материалов.

- `app/` — backend API и frontend приложения.
- `llm/` — отдельный HTTP-сервис интеграции с локальной LLM.

Сервисы запускаются в Docker и общаются по HTTP внутри Docker-сети. API приложения будет доступно внешним клиентам.
