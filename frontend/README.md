# Frontend — макет Максидома

Локальная демонстрационная витрина для хакатона по мотивам https://www.maxidom.ru/. Это адаптивный макет, а не точная копия действующего магазина. Ассортимент, цены и предложения вымышлены.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

Для запуска через локальный HTTP-сервер из корня проекта:

```sh
python3 -m http.server 8080 --directory frontend
```

Затем откройте http://localhost:8080.

## Что работает

- Каталог, категории, поиск по названию и категории, подборки скидок и хитов.
- Избранное, корзина с изменением количества и расчётом суммы.
- Выбор города, переключение баннеров, информационные окна.
- Сохранение корзины, избранного и города в `localStorage`, если оно доступно.
- Адаптация под телефон, планшет и компьютер.

HTML, CSS и обычный JavaScript. Все иллюстрации SVG лежат в `assets/`; шрифты системные. Внешних CDN, запросов к API, аналитики и подключений к Rust/Axum нет. Авторизация и оформление заказа представлены информационными заглушками. Файлы в дальнейшем можно раздавать как статику через Axum.

`app.js` содержит демонстрационные данные и логику интерфейса, `styles.css` — оформление и адаптивную сетку.
