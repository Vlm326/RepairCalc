# Frontend — макет Максидома

Локальная демонстрационная витрина для хакатона по мотивам https://www.maxidom.ru/. Это адаптивный макет, а не точная копия действующего магазина. Ассортимент, цены и предложения вымышлены.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

Для запуска через локальный HTTP-сервер из корня проекта:

```sh
python3 -m http.server 8080 --directory frontend
```

Затем откройте http://localhost:8080.

## Что работает

- Каталог, категории, поиск по названию и категории, подборки скидок и хитов.
- Меню «Калькулятор ремонта» и баннер на главной: сценарий «Объект → Комнаты → Работы → Смета» из `RepairCalc_demo.html`, оформленный в стиле витрины.
- Несколько комнат, размеры и проёмы, выбор отделки, подготовительных и инженерных работ, запас, упаковки, смета и замена демонстрационных материалов. Возврат в каталог сохраняет текущий расчёт до перезагрузки страницы.
- Избранное, корзина с изменением количества и расчётом суммы.
- Выбор города, переключение баннеров, информационные окна.
- Сохранение корзины, избранного и города в `localStorage`, если оно доступно.
- Адаптация под телефон, планшет и компьютер.

HTML, CSS и обычный JavaScript. Все иллюстрации SVG лежат в `assets/`; шрифты системные. Внешних CDN, запросов к API, аналитики и подключений к Rust/Axum нет. Авторизация и оформление заказа представлены информационными заглушками. Файлы в дальнейшем можно раздавать как статику через Axum.

`app.js` содержит демонстрационные данные и логику интерфейса, `styles.css` — оформление и адаптивную сетку.

## Калькулятор ремонта

Откройте `index.html#calculator` или нажмите «Калькулятор ремонта» в верхнем меню,
каталоге или подвале. На главной есть кнопка «Рассчитать ремонт».
Для быстрого просмотра нажмите «Заполнить пример: санузел и комната»,
затем перейдите к работам и смете. Формы адаптированы для телефона.

`calculator.js` содержит изолированное состояние и сценарий исходной демки,
`calculator.css` — стили в палитре магазина. Сам файл `RepairCalc_demo.html`
не меняется и не загружается во фрейме. Калькулятор работает без CDN и сборки.

Это UI-прототип: нормы расхода и ассортимент взяты из демки; цены вымышлены,
смета не включает труд и доставку. Браузерные расчёты пока не вызывают Rust-модуль
`calculation` и не читают PostgreSQL. Вариант «Плюс» — демонстрационная замена.
«Собрать список покупок» фиксирует результат на экране, заказ не оформляется.
